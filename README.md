# conduit-processor-sdk-python (archived)

This repository is archived. It was an unreleased experiment in compiling Python processors to WASM.

Python processors move to the gRPC processor runtime planned for Conduit v0.24. See
[`docs/design-documents/20261008-sdk-parity-and-open-plugin-protocol.md`](https://github.com/ConduitIO/conduit/blob/docs/sdk-parity-design/docs/design-documents/20261008-sdk-parity-and-open-plugin-protocol.md)
in ConduitIO/conduit ([PR #2948](https://github.com/ConduitIO/conduit/pull/2948)).

For Python connectors, see [ConduitIO/conduit-connector-sdk-python](https://github.com/ConduitIO/conduit-connector-sdk-python).
